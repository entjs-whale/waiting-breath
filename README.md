# 기다리는 숨

새끼 향고래의 눈으로, 깊은 바다로 내려간 엄마를 기다리는 장면.
숨의 바다 · 화면구성 컨셉 v1.16 · 실사 형태 + 양모펠트

- 양모펠트 향고래 원작: humming whales
- 기획·구성: whales.breathe

👉 https://entjs-whale.github.io/waiting-breath/

## 관람 환경
대부분의 PC·스마트폰·태블릿 브라우저(최신 Chrome, Safari, Edge)에서 열립니다.
작품은 두 가지 그래픽 방식을 갖고 있어, 기기에 맞는 쪽을 스스로 고릅니다.

| 방식 | 쓰이는 곳 | 특징 |
|---|---|---|
| WebGPU | PC Chrome·Edge, iOS·iPadOS 26 이상 Safari, 일부 안드로이드 Chrome | 가장 부드럽게 보입니다 |
| WebGL 2 | 그 밖의 거의 모든 기기 (iOS 15 이상, 안드로이드 Chrome·삼성 인터넷 등) | 같은 장면을 그립니다. 기기 성능에 따라 화질이 자동으로 낮아질 수 있습니다 |

- 카카오톡·인스타그램·네이버 앱 안에서 열렸다면 ‘다른 브라우저로 열기’를 눌러 주세요(앱 안에서도 열리는 경우가 많지만 소리·전체 화면이 제한될 수 있습니다).
- 주소 끝에 `?gl`을 붙이면 WebGL 2 방식으로 열어 볼 수 있습니다(점검용).
- 헤드폰을 쓰면 소리의 방향과 깊이가 들립니다.
- 한 번 연 뒤 공유 → ‘홈 화면에 추가’를 하면 인터넷 없이도 열립니다.

## 파일
- `index.html` — 작품 페이지
- `sw.js` — 첫 방문 때 작품을 기기에 저장해, 이후 인터넷 없이 열리게 함
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — 홈 화면 아이콘과 전체 화면 실행 설정

## 업데이트할 때
`index.html`을 바꾸면 `sw.js` 첫 줄의 `VERSION` 값도 바꿔 주세요(예: v1.16 → v1.17).
그래야 아이패드가 인터넷에 연결됐을 때 새 버전을 받아 저장합니다.
